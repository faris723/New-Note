# Catatan Pintar 1.0.13

- Perbaikan ekspor PDF: satu file PDF berisi banyak catatan, setiap catatan dimulai pada halaman baru dan catatan panjang dapat berlanjut ke halaman berikutnya.
- Ekspor Android menampilkan lokasi penyimpanan: `Download/Catatan Pintar/`.
- Pemeriksaan pembaruan diperkuat dengan fallback GitHub Releases API dan feed Releases Atom untuk Android/WebView yang bermasalah dengan preflight/API.
- Tampilan Keuangan diringkas menjadi 2 kolom per baris pada layar HP.
- Tombol riwayat per bagian Keuangan tetap tersedia.
