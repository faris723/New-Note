# Catatan Pintar 1.0.12

- Perbaikan layout modal Impor/Ekspor pada layar HP agar tombol bawah tidak tertutup toolbar navigasi.
- Impor menampilkan status dan progres yang jelas sampai selesai.
- Cadangan JSON sekarang ikut membawa data keuangan: kewajiban, tabungan, dan riwayat.
- Data `funding`, `incomeFrom`, dan `expenseFor` pada transaksi dipertahankan saat ekspor/impor.
- Ekspor keuangan memakai penyimpanan universal aplikasi, termasuk jalur Android native.
- Dashboard Keuangan diubah menjadi 6 bagian: Saldo Bersih, Pemasukan, Pengeluaran, Hutang, Tabungan, dan Pengeluaran Wajib.
- Setiap bagian memiliki tombol riwayat khusus untuk bagian tersebut.
- Pada APK native, tombol instalasi PWA tidak ditampilkan; diganti dengan Periksa Pembaruan.
