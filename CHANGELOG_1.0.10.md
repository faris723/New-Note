# Catatan Pintar 1.0.10

## Perbaikan lampiran, sisipan file, dan PDF
- Menghapus chip sisipan teks saat lampiran terkait dihapus.
- Membersihkan chip sisipan yatim saat catatan dibuka kembali.
- Memperkuat tombol **📎 File** agar file picker Android/WebView dapat dibuka dan posisi kursor tersimpan.
- Sisipan file umum tetap menjadi lampiran normal dan dapat dibuka melalui chip **lihat**.
- Pratinjau PDF pada web/GitHub Pages sekarang menggunakan PDF.js; Android tetap menggunakan PdfViewer native.
- Menambahkan `worker-src blob:` pada CSP untuk PDF.js.
- versionName 1.0.10 / versionCode 11.
