# Catatan Pintar 1.0.6

- Dana Wajib dapat dibayar bertahap/cicilan dengan progres target.
- Pembayaran hutang dapat dicicil, menggunakan satu atau beberapa sumber dana, dengan progres terbayar/sisa.
- Setiap pembayaran menyimpan sumber dana dan riwayat.
- Jadwal menampilkan jam acara pada daftar tanggal terpilih.
- Catatan Keuangan dan Acara disembunyikan dari daftar/kategori Catatan utama dan hanya diakses melalui toolbar masing-masing.
- Toolbar Catatan/Keuangan/Jadwal dibuat full-width di bagian bawah; tombol + dan Tanya Jawab dinaikkan agar tidak tertutup navigation bar.
- Pemeriksaan update dijalankan saat startup, setelah UI siap, dan ketika APK kembali aktif/foreground.
- Update checker tidak mensyaratkan nama asset tertentu untuk menampilkan notifikasi; bila APK tidak ditemukan, pengguna diarahkan ke halaman release.
