Pasang aplikasi ini di ponsel atau komputer Anda agar dapat dibuka langsung dari layar utama tanpa browser dan dapat digunakan secara 100% offline.

📱 Di HP Android (Chrome / Edge):
  1. Tekan tombol hijau Pasang Aplikasi Sekarang di atas, ATAU
  2. Tekan menu titik tiga (⋮) di pojok kanan atas browser, lalu pilih "Instal aplikasi" atau "Tambahkan ke Layar Utama".
🍎 Di iPhone / iPad (Safari):
  1. Buka situs ini di browser Safari.
  2. Tekan tombol Bagikan (Share) 📤 di bilah bawah layar.

💻 Di Laptop / Komputer (Chrome / Edge):

Klik ikon pasang aplikasi ⊕ yang muncul di bilah alamat URL browser Anda.

🛡️ Isolasi Data & Keamanan Anti-Hapus

Ruang Penyimpanan Aktif:
📱 Mode Aplikasi (Data Terisolasi)
⚠️ Kenapa Data PWA Terhapus Saat Bersihkan Data Browser?

Aplikasi PWA diinstal melalui Chrome, sehingga sistem operasi menganggap datanya berada di bawah wadah penjelajah Chrome. Ketika Anda memilih "Hapus cookie dan data situs" di Chrome, browser secara otomatis menyapu bersih seluruh basis data situs web dan PWA.

⭐ Solusi Terbaik: Aplikasi Android Asli (.APK)

Berjalan 100% mandiri tanpa browser. Memiliki folder sistem sendiri (/data/data/com.catatanpintar.app) yang kebal dan tidak akan pernah terpengaruh pembersihan data Chrome!

📁 Solusi Web/PWA: Brankas Berkas Fisik (Anti-Hapus)

Hubungkan catatan langsung ke berkas fisik di memori perangkat Anda (misal folder Dokumen/Unduhan). Karena berkas ini berada di luar wadah browser, membersihkan cookie browser TIDAK AKAN menghapusnya!

⚪ Belum terhubung ke berkas fisik perangkat.

📱 Aplikasi Android Mandiri (APK)

🛡️ Benar-Benar Berdiri Sendiri 100% Tanpa Browser:

Aplikasi APK terpasang sebagai aplikasi Android murni (com.catatanpintar.app). Sistem operasi Android mengisolasinya secara penuh. Anda dapat membersihkan cache browser Chrome kapan saja tanpa takut data catatan Anda terhapus!

Langkah Mendapatkan & Memasang APK:
  1. Melalui GitHub Actions (Otomatis):
    Setiap kali proyek diperbarui di repositori GitHub, alur kerja otomatis Build Android APK akan menghasilkan berkas app-debug.apk yang dapat langsung diunduh di tab Actions repositori GitHub Anda.
  2. Melalui Komputer (Android Studio / Gradle):
    Jalankan perintah berikut di folder proyek: 
    npx cap sync android
cd android
./gradlew assembleDebug
    Berkas APK akan langsung jadi di:
    android/app/build/outputs/apk/debug/app-debug.apk
  3. Pasang di HP Android:
    Kirim berkas APK tersebut ke HP Anda (lewat WhatsApp, Drive, atau kabel data), lalu ketuk berkas tersebut untuk memasangnya.
