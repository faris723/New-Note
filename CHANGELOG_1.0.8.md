# Catatan Pintar 1.0.8

- Memperbaiki teks anotasi gambar agar dapat dipilih dan dipindahkan dengan drag.
- Menambahkan layer teks anotasi terpisah sehingga Undo/Redo dan pemindahan teks lebih aman.
- Memperbaiki alur anotasi agar menambahkan gambar ke catatan yang sedang diedit tanpa menghapus lampiran sebelumnya, sekaligus menyisipkan chip gambar pada posisi kursor.
- Menambahkan tombol **📎 File** untuk menyisipkan satu atau beberapa berkas langsung pada posisi kursor di teks catatan.
- Menambahkan chip lampiran inline yang dapat diketuk untuk membuka pratinjau di dalam aplikasi.
- Memperkuat pratinjau berkas umum dan penyimpanan metadata lampiran pada berkas `.cnote`.
- Toolbar bawah Keuangan/Jadwal/Catatan dibuat memenuhi lebar layar.
- Tombol `+` dan Tanya Jawab dinaikkan agar tidak bertabrakan dengan toolbar bawah.
- Versi Android: `1.0.8`, `versionCode 9`; applicationId dan signing key kompatibilitas tetap dipertahankan.
